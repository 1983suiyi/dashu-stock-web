# 大数选股管理工具

基于《大数投资》公开可得方法论抽象出来的 Web 选股工作台，已接入**免费、无需注册**的真实 A 股数据，
评分算法**还原自「大数模拟器」公开前端产物**（非自拟权重）。

## 评分算法（三好学生评分，300 分制）

```text
q        = 历史折扣 >= 1 ? 1 : 0.618 + 历史折扣 × 0.382
bta(lo,hi,v) = v >= hi ? 0 : (v <= lo ? 1 : 1 - (v - lo) / (hi - lo))

PB 得分  = bta(q,   2q,  PB) × 100      取值范围 [q, 2q]
PE 得分  = bta(10q, 20q, PE) × 100      取值范围 [10q, 20q]
涨幅得分 = 涨幅 <= 0 ? 100 : max(0, 100 - 200 × 涨幅)
涨幅     = (现价 - 一年内最低价) / 一年内最低价

三好学生评分 = PB 得分 + PE 得分 + 涨幅得分   （满分 300）
绝对胜算概率 = 三好学生评分 / 3              （%）
```

因此 **200 分门槛 ≡ 66.67% ≡ 2/3 胜算**，与 2/3 仓位上限同源。

筛选口径：`>200 分`、`股息率 > 1%`、`资产负债率 ≤ 行业资产负债率中位数 × 1.15（宽容 15%）`、`商誉占净资产 < 20%`、`股权质押比例 < 20%`、满配过滤单行业 `> 3%`。

## 行业口径（公开、可复现）

「资产负债率 ≤ 行业资产负债率中位数 × 1.15」中的**中位数**，本项目采用**完全可复现的公开口径**：

1. 行业原始字段取自东方财富公开接口的 `BOARD_NAME`；
2. 经 [industry.ts](file:///Users/yisui/Documents/Trae/temp_20261105_01/src/lib/industry.ts) 归一化为「一级行业 + 细分行业」两层（别名表未覆盖时保守回退为「去层级值作一级、原值作细分」）；
3. **以本次拉取到的全市场样本**按细分行业分组，取资产负债率中位数（偶数个取中间两数均值），见 [strategy.ts](file:///Users/yisui/Documents/Trae/temp_20261105_01/src/lib/strategy.ts#L73-L89)。

**宽容幅度**：判定上限 = 行业中位数 × (1 + `debtMedianTolerance`)，默认 `0.15`（即 +15%），可在界面「规则配置」里调整。放宽的原因是中位数本身取整与股票池口径存在差异，紧贴中位数的优质股容易被误杀。

### 与「大数模拟器」的差异说明

「大数模拟器」页面上的细分行业资产负债率中位数是其**后端私有快照下发的一个行业级常量**，并非按导出列表现算，公开数据无法复现该值。因此：

- 本项目**不追求与模拟器数值完全一致**，只保证口径公开、可复现、可解释；
- 模拟器导出文件**仅用于对比校验**，由 [compare_simulator_export.mts](file:///Users/yisui/Documents/Trae/temp_20261105_01/scripts/compare_simulator_export.mts) 承载，**不进入任何运行时逻辑**，也未被产品代码引用。

| 用途 | 数据源 | 说明 |
| --- | --- | --- |
| 估值 / 财务 / 行业主表 | **东方财富数据中心公开接口** | 响应头带 `Access-Control-Allow-Origin: *`，浏览器可直连，无需后端 |
| 近 12 个月分红明细 | **东方财富数据中心公开接口** | 报表 `RPT_SHAREBONUS_DET`，用于换算股息率 |

| 股权质押风险 | **东方财富数据中心公开接口** | 报表 `RPT_CSDC_LIST_NEWEST`，用于读取最新质押比例 |
| 现价 / 一年低价 / 三年低价 | **腾讯行情快照 + 腾讯历史 K 线** | 经本地 `/api/kline` 代理补齐；现价优先使用腾讯最新快照，用于计算涨1、涨3与涨幅得分 |

| 特性 | 实测结果 |
| --- | --- |
| 费用 | 免费，无需注册、无需 token |
| 跨域 | `Access-Control-Allow-Origin: *`，**浏览器可直连** |
| 覆盖 | 全 A 股 5223 只，128 个行业 |

实际使用的六张报表：

| 报表 | 提供字段 |
| --- | --- |
| `RPT_VALUEANALYSIS_DET` | PB、PE(TTM)、PS(TTM)、交易日快照价、总市值、行业 |
| `RPT_DMSK_FN_BALANCE` | 资产负债率、总资产、净资产 |
| `RPT_LICO_FN_CPD` | 加权 ROE、每股收益、净利润、毛利率 |
| `RPT_SHAREBONUS_DET` | 分红方案、除权除息日、每 10 股税前派息 |
| `RPT_GOODWILL_STOCKDETAILS` | 报告期商誉、净资产、商誉占净资产比例 |
| `RPT_CSDC_LIST_NEWEST` | 最新交易日质押比例、质押笔数、质押市值 |

**股息率口径**：`Σ(近 12 个月已实施税前每 10 股派息) ÷ 10 ÷ 现价 × 100`。
只计入 `EX_DIVIDEND_DATE`（除权除息日）落在近 12 个月的「实施分配」记录，未实施预案不计入；
期间无分红记录按 **0%** 处理（而非空值），以保证「股息率 > 1%」过滤真实生效。
实测与模拟器导出对比：中国太保 4.92% vs 5.0、深圳燃气 2.50% vs 2.5、北京人力 7.86% vs 7.9。

**公开风险过滤（当前版本）**：
- 商誉占净资产 `>= 20%` 视为高风险，不进入推荐列表；
- 股权质押比例 `>= 20%` 视为高风险，不进入推荐列表。

这两条是当前公开可复现的「扫雷」落地版本，用于先拦截类似锦泓集团这类高商誉样本；完整扫雷分数后续再继续补齐。

### 关于其他数据源

- **Tushare**：免费额度仅 120 积分，只能取非复权日线；取财务因子需 2000 积分（约 ¥200/年），**不属于免费方案**。
- **AkShare / BaoStock**：同样免费且数据质量好，但均为 **Python 库**，必须自建 Python 后端，无法被浏览器直连。

## 当前能力

- 一键拉取全市场最新公开快照（估值 + 财务 + 行业 + 分红 + 商誉 + 质押），并用腾讯快照刷新现价，再自动补齐一年/三年低价
- **Web 端直接展示选股列表**（名称/代码、行业/细分、你的持仓、大数分、PB、PE、现价、涨1、涨3、扫雷宝、总市值、股息率、质押率、商誉、资产负债、状态、风险提示）
- **持仓录入**：支持手动添加持仓，或导入同花顺/通用券商 CSV；持仓页与持仓汇总页均以你的实际持仓为准，不再由系统自动生成
- **导出 CSV**：「大数评分表」「当前持仓」两张表（UTF-8 BOM，Excel 打开不乱码）
- 市场估值快照与仓位建议联动（全市场 PB/PE 中位数自动计算）
- 两阶段剪枝补齐 K 线：只为可能及格的候选请求，结果精确不丢候选
- 行业分层抽样与组合推荐、2/3 权益仓位上限控制
- CSV 股票池导入 / 持仓 CSV 导入 / 演示数据回退
- 淘汰原因与缺失字段可解释
- **PB 底偏离着色**：评分表 PB 列按「个股 PB 相对同细分行业 PB 底」的偏离着色，一眼区分相对便宜与相对偏贵

### PB 底偏离着色口径

目的是在评分表里快速识别**相对便宜**的票。口径完全公开、可复现：

1. **PB 底** = 该细分行业内最低的正 PB（与「细分行业」表的 PB底 同源）；
2. **偏离幅度** = `个股 PB ÷ 行业 PB 底 − 1`，因 PB 底是行业最小值，该值恒 ≥ 0；
3. **分档着色**：

| 偏离幅度 | 颜色 | 含义 |
| --- | --- | --- |
| ≤ 10% | 绿 | 贴近行业 PB 底，相对便宜 |
| 10% ~ 20% | 黄 | 已离开底部 |
| ≥ 20% | 红 | 明显偏离行业底部 |

阈值定义在 [strategy.ts](file:///Users/yisui/Documents/Trae/temp_20261105_01/src/lib/strategy.ts#L27-L29)（`PB_FLOOR_NEAR_PCT` / `PB_FLOOR_FAR_PCT`）。该着色**只做展示**，不参与评分与筛选；鼠标悬停 PB 单元格可看到具体偏离幅度与行业 PB 底。

## 本地运行

```bash
npm install
npm run dev        # 开发：Vite + 内置 /api/kline 中间件
```

## 构建与启动

```bash
npm run build      # tsc -b && vite build
npm run lint
npm start          # 生产：node server/index.mjs，同时提供 /api/kline 与 dist 静态站点
```

默认端口 `8787`，可用 `PORT` 覆盖，例如 `PORT=8791 npm start`。

```text
code,name,industry,price,pb,pe,ps,roe,debtRatio,dividendYield,marketCap,lowPrice1y,lowPrice3y,goodwillRatio,pledgeRatio,isST
```

空单元格会被解析为空值（而非 0），示例模板见 `docs/example-stocks-template.csv`。

## 已知限制

- 数据来自公开网页接口而非官方 API，字段与参数可能随时调整；已做空值兜底与错误提示。
- 退市整理期股票（名称含「退」）已剔除，避免极低 PB 污染低估值选股。
- 股息率、商誉占净资产、股权质押比例均已接入公开数据口径；当前仅先实现 `20%` 的高风险硬过滤，完整扫雷分数仍待补齐。
- 行业资产负债率中位数与「大数模拟器」数值不一致属预期（口径来源不同，详见上文「行业口径」）。
- 三年低价依赖腾讯历史 K 线（`proxy.finance.qq.com`）逐只补齐，速度慢于一年低价快照；当前仍依赖候选剪枝控制耗时。
- 无持久化：刷新页面后需重新拉取。
